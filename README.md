# humanizer-zh

面向 GPT、Claude 等大模型的中文自然化编辑 Skill。它用于减少翻译腔、模板腔和聊天残留，同时守住原意、作者立场、文体、受保护内容与文件操作授权。

本 Skill 不判断文本是否由 AI 生成，也不把普通润色冒充摘要、扩写、事实核查、来源验证或抄袭检测。

## 设计结论

采用“两层、两文件”的轻量结构：

```text
humanizer-zh/
├── SKILL.md
├── README.md
└── references/
    └── conditional-modes.md
```

- `SKILL.md`：常驻规则，包含任务边界、忠实改写契约和 5 步执行流程。
- `references/conditional-modes.md`：仅在摘要／压缩、扩写／创作、事实／来源核查或特定文体需要时读取。
- `README.md`：开发与验证说明，不属于 Skill 的模型运行上下文。

没有继续按文体或表达模式拆成更多文件。过度拆分会增加漏读、重复和规则漂移；合成单文件虽然可行，但会让每个普通润色任务都加载条件模式。当前轻拆使默认任务少加载约 39.9% 的运行时文本，同时只增加一次直接引用。

## 优化目标

1. 让“自然一点”“去 AI 味”“润色”默认表示忠实改写，不自动扩大权限。
2. 保留事实、主张、归因、立场、限制、不确定程度与规范词强度。
3. 把中文本土化落实为信息顺序、主语、搭配、语域和渠道适配，不使用词语黑名单。
4. 区分审阅、写回文件、摘要、创作和核查，避免模型自行跨任务。
5. 删除 GPT、Claude 通常可以推断的重复解释，只保留容易误判或造成语义损失的规则。

## 优化过程量化

| 阶段 | 产出与数量 | 结果 |
|---|---|---|
| 需求冻结 | 1 份 `requirements.md` | 明确目标、非目标、质量维度、成本和停止条件 |
| 用例冻结 | 13 例 | 9 个可见用例、4 个密封用例；用户确认全部保留 |
| 不可变基线 | 2 个运行时文档 | `SKILL.md` 与 `patterns.md` 均有 SHA-256 绑定 |
| 隔离构建 | 1 个候选 | 构建者只看到需求和可见集，未看到密封集 |
| 结构检查 | 0 errors、0 warnings | 无风险提示、无未知项 |
| 标准主机矩阵 | 18 条观察 | 基线 9 条、候选 9 条；全部为相同基础设施错误 |
| 补充显式执行 | 9 个结果文件 | 由未参与构建、未读取密封集与验证器的 subagent 生成 |
| 因果修订 | 1 次、1 条规则 | 只修复明确长度约束的实际计数问题 |

整个过程没有新增脚本、资产、多层引用或额外规则系统，也没有修改冻结用例和验证器。

## 核心行为变化

- 默认忠实改写，不擅自摘要、扩写、删减或核查。
- 普通润色保留原有归因和不确定程度，来源可疑时只另作提示。
- 保留代码、frontmatter、链接目标、引文、术语、数字和规范词强度。
- 查看、解释和审阅默认只读；只有明确授权才写回指定文件与范围。
- 营销、客服、社交媒体、技术、法律、公文和个人写作分别校准，不统一改成中性说明文。
- 原文已经自然准确时少改或不改，不为展示工作量机械重写。
- 拒绝编造 AI 作者身份概率，可改为提供表达层面的审阅。

### 已确认

- 当前运行时结构检查通过：0 errors、0 warnings、0 risk findings、0 risk unknowns。
- 运行时树摘要：`sha256:fceed683b455a766d63aea856271561accd38d825a100705b8d6c9222ab760ef`。
- 9 个可见用例均生成了结果文件。
- 带硬约束的补充结果保留了术语、数字、归因、情态强度、受保护内容和文件审阅边界。
- `.DS_Store` 与旧 `patterns.md` 不进入当前运行时目录。

### 未证明

- Skill Forge 正式决策是 `inconclusive`，不是“候选已证明优于基线”。
- Codex CLI `0.133.0` 的 18 条标准观察均因 `Operation not permitted` 无法初始化 app-server；这是基础设施错误，不是候选失败。
- 冻结要求不允许调用外部付费模型，因此没有提权重跑模型矩阵。
- 密封集、Claude 行为、自动路由、主机激活、长期稳定性和选定用例之外的泛化均未验证。

### 验证器已知问题

冻结验证器存在两处可复现误报，本轮保持原哈希且没有修改：

1. 对实际文本做 NFKC 后，中文逗号会变成英文逗号，但验证器仍用未归一化的中文字面量比较，可能把逐字保留的引文报为缺失。
2. 正则 `\bv2\b` 无法匹配“回滚到v2”，因为 Unicode 规则下汉字和字母都属于词字符，二者之间不存在 `\b`。

因此，验证器的非零退出码必须结合原始文件检查，不能直接归为 Skill 失败。

## 使用方式

当宿主已经正确安装并显式提供本 Skill 时，可以用于：

- “把这段技术译文润色成自然中文，保留术语和数字。”
- “参考这段作者样本调整语气，不要新增观点。”
- “只审阅这份文件的翻译腔，不要修改文件。”
- “压缩到 100 字以内，重点保留时间和回滚条件。”

本目录存在并不等于 Codex 或 Claude 已自动发现、激活或路由到该 Skill；这些能力取决于宿主的安装位置与运行机制。
